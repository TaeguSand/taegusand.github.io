О проекте

Проект «День»

Простой сайт-трекер без регистрации и рекламы. Помогает следить за тремя базовыми привычками.

Зачем этот сайт

Большинство приложений для здоровья требуют регистрации, подписок и разрешений. Здесь ничего этого нет. Просто открыл — отметил — закрыл. Данные хранятся только в твоём браузере.

Что внутри

  • Главная — трекер трёх привычек.
  • Вода — калькулятор нормы и трекер стаканов.
  • Сон — расчёт циклов сна.
  • Активность — цель по шагам.
  • Статистика — графики прогресса.
  • Награды — значки за достижения.
  • Мотивация — цитаты и напоминания.

Технологии

Чистый HTML, CSS и JavaScript. Без фреймворков. Данные — localStorage.

Важно: этот сайт — не медицинский инструмент. Все расчёты приблизительные.

Ключевые принципы

Без регистрации и лишних данных.
Данные не покидают браузер.
Никаких подписок и рекламы.
Простой интерфейс без лишних настроек.
Работает офлайн после первой загрузки.
Открытый код — можно посмотреть и изучить.
